# Home

Home shows your costs, recent jobs and desktops, then quick links.

The cost card compares this month so far with the full previous calendar month. It contains the snapshot's **As of** time, five tiles for Jobs, Desktops, Desktop disks, Shared storage and AI, and a grouped comparison chart. **Known costs** includes available amounts; **Estimated costs** indicates complete coverage. Unknown amounts display **--**, while confirmed zero usage displays zero. Coverage badges explain Partial, No data, Estimated share and Collecting states.

Select **View My costs** or a cost tile to open the daily charts. Unknown days are omitted and listed beside each chart. Folder usage and quotas are available in a separate expandable section; all calculation rules and exclusions are in **How it is calculated** at the bottom.

The leader collects every user's costs at startup and every 15 minutes. Opening Home reads a durable snapshot. **Collecting · about N min** shows the collector's estimated readiness time for a new user or cluster. The MTD navigation ticker reads the same stored total. On My costs, **Refresh** requests background collection and preserves the visible amounts until a new generation is ready.
