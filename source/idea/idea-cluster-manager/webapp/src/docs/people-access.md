## People and access

Users and Groups manage accounts and memberships. Desktop permissions manages capability profiles. Reconciliation runs provides Run now and reports; edit periodic policy under Settings > Account synchronization.

Both views load saved settings from the settings table. In Settings, **Reconciliation on** reflects the saved on/off value and saves immediately. Advanced edits apply only after **Save reconciliation settings**; saves notify the periodic worker. **Next run at** shows Off, Due now, or the last periodic checkpoint plus the saved interval.

In Reconciliation runs, **Last run at / result** shows the latest manual or periodic result and whether it was a dry run or apply. Status refreshes every ten seconds. Run **Run now (dry run)** first, then **Run now (apply)** after reviewing the report. These actions use saved settings and are available even when periodic reconciliation is off. Reopening the page restores the saved report; a notice identifies reports limited to the first 100 rows.
