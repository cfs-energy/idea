## My desktops

Use Owned for your desktops and Shared for desktops shared with you. Launch, connect, schedule and share from the existing desktop actions.

The **Idle stop** badge appears only on days whose schedule runs the idle check. If a Red Hat Enterprise Linux or Rocky Linux desktop returns on the old kernel, bootstrap records the mismatch and exits immediately. The timeout sweep later marks the session **ERROR** and terminates the host.
